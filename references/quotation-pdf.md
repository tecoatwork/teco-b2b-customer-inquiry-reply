# 针对性报价PDF制作规范

Copyright (c) 2026 tecoatwork

## 先把报价内容确认好

复用已授权资料及当次明确确认，不重新问已知信息。只补影响本次报价的关键缺口：

- 买卖双方：客户公司、联系人；我方公司名称、官网、邮箱、电话，适用时补法定签约主体与地址。
- 产品：客户选定型号、用途、关键配置、电压/插头或其他适用参数、配件包含范围、包装。
- 金额：有效单价、币种、计价单位、报价数量及MOQ，选配件独立价格、税运费包含范围。
- 条件：贸易术语与地点、付款、交期及起算条件、保修、报价有效期。
- 项目安排：样品数量、费用、运输及退费。分别确认样品货值、快递费、税费；“退样品费”不自动包括运费。退款不能擅自改成抵货款；订单门槛、触发节点、金额、方式和时间不全时标待确认。

不要为凑正式外观编造地址、税号、签名、印章或认证。可创建注明草案用途的文档编号，不冒充财务系统已签发编号。日期按用户时区。用户提供的商号不自动成为已核验的法定主体。

## 一页报价的默认结构

优先客户语言、A4纵向、清晰品牌字标和表格；内容较多时自然分页，不为一页压小字号。

1. 抬头：品牌/公司、客户专属方案标题、编号、版本及日期，必要的Draft状态。
2. 双方信息：Prepared for / Prepared by；官网及邮箱设可点击链接。
3. 客户需求与方案：两三句话说明已确认的用途、产品线或障碍，以及本方案如何对应。
4. 产品价格表：型号/配置、数量或MOQ、单价；选配件单列。订购数量未知时不把MOQ当订单量计算总额。
5. 项目专属安排：确实相关的定制包装、样品、物流或获批让步。注明适用条件和费用边界。
6. 验证及商业条件：已有证据与建议测试分开，列清贸易、付款、交期、有效期等必要条款。
7. 页脚：版本/状态及页码；有正式批准才标正式报价，不伪造签字。

不加入“NEXT STEP”标题、CTA、会议邀请或采购催促。需要下一步时写入配套邮件，不嵌入报价PDF。

## 如何体现量身定制

用“客户要求 → 方案选择 → 理由/依据 → 条件”串联：已选型号就不重新堆推荐；实际产品线可作为适配验证对象；家用/专业等场景须有本型号依据；按需求定制包装不意味着定制免费或无限改稿。

只写与选择有关的差异。没有真实竞品测试，不宣称优于别人；没有测试不写已兼容；不要套用相邻型号参数。针对历史费用分歧的已批调整可以突出，但先付后退仍不等于免付，也不能说客户已接受。

## 草案与正式报价

- 草案：醒目标注“QUOTATION DRAFT / FOR REVIEW”。历史价注明原日期及待复核；未定项写TBC。无有效价格时留待确认，不编参考数字。不要使用Proforma Invoice冒充报价。
- 正式报价：关键配置、金额、责任主体及交易条件经用户批准，且没有影响履约的关键缺项。不能仅因用户说“official一些”就去掉草案标识。
- 更新：用户补一项信息，只改相应事实及受影响金额/条件，保留其余有效内容；明确请求删除的章节不在下一版本自动恢复。

## 实际制作与验收

使用宿主当前可用PDF工具/技能；可用时遵循该工具的制作规范。也可使用ReportLab或等效PDF引擎，并用Poppler或可用渲染器检查。无需安装或运行本包脚本，本包不包含PDF引擎。工具不可用时明确说明，不能把Markdown称为PDF。

生成到用户指定位置，未指定则用本次任务输出目录；公共Skill目录不存客户输出。保留可编辑源文件或生成源代码在任务目录，方便局部修改。

交付前：
- 核对型号、数量、单位、币种、单价及总额计算；未知价格不参与计算，标准/选配不可混写。
- 核对旧价与现价、含税/运费范围、退款与抵扣、承诺及草案状态。
- 检查公司联系方式与链接，不擅自复用其他项目的客户或供应商信息。
- 渲染所有页面查看：表格不截断、文字不重叠、字体可读、页码正确、无多余空白页；未通过时修复再交付。
- 确认默认无NEXT STEP/CTA；提供实际文件链接并说明草案或正式状态。生成不代表已发送。
