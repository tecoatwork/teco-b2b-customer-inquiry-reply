# B2B询盘分析和回复

一个用于分析B2B询盘、理解客户及联系人，并起草简短有效回复的 Skill。

Copyright (c) 2026 tecoatwork

核心思路：客户与需求分析 → FABMP价值匹配 → 差异化报价策略 → 简洁回复 → 事实与承诺审核。先理解客户为什么问，再帮助客户看懂方案、价格依据与取舍。

## 询盘拆解与回复策略

先读取已授权的公司、产品、行业和客户研究资料，逐项拆解询盘。区分客户已确认信息、需要澄清的歧义和我方假设。优先处理会改变选型、价格或可行性的缺口；已知部分先答，不重复询问已有答案。

内部使用《询盘问题与回复策略表》：客户问题/要求｜已知事实与来源｜关键缺口｜本次处理方式｜回复依据。处理方式可为直接回答、部分回答并澄清、提供有条件方案或内部确认。此表供判断与教学，不整张发给客户。

## 设计者的五点思路

### 1. 分析客户公司、产品线与询盘动机

分析客户的公司和产品线，了解背景信息以及发询盘的动机。

研究客户卖什么、服务谁、现有产品如何定位，以及本次询盘产品与其业务的关系。结合询盘判断：客户可能是在扩充产品线、寻找替代供应商、解决质量问题、为具体项目选型，还是初步了解价格。

这些信息应影响回复中的适用场景、差异化卖点和下一步问题。已核实背景与动机推测分别呈现，不把“可能需要”当成“正在采购”。

### 2. 分析询盘人的职位与个人工作 Meaning

分析发询盘人的职位，思考他们个人工作所追求的 Meaning。

公司想得到的业务结果，与联系人希望在工作中实现的意义，需要分开理解。例如，公司可能希望降低质量成本；采购负责人可能希望自己的供应商选择有据可依，产品经理可能希望推动新品顺利上市，工程人员可能希望减少验证和返工负担。

Meaning 应基于实际角色、询盘内容和工作情境提出假设，并在后续沟通中校正。回复应体现对其工作的帮助，不直接揣测或点破个人心理。

### 3. 使用 FABMP 作为回复的核心思路

| 要素 | 含义 | 在询盘回复中的问题 |
| --- | --- | --- |
| F — Feature | 产品或服务特征 | 我们具体做了什么？ |
| A — Advantage | 相对优势 | 这项设计或工艺在什么条件下更有优势？ |
| B — Benefit | 客户公司的业务收益 | 它如何影响成本、质量、销售、交付或上市？ |
| M — Meaning | 联系人的工作意义 | 这个结果对他完成工作有什么帮助？ |
| P — Proof | 证据与验证 | 客户凭什么相信，如何核验？ |

内部先完成完整价值链，对外不机械罗列五个字母。每次只选择一个与当前询盘最相关的价值主题，将工艺、收益、角色意义与证据连起来。

### 4. 差异化报价与简洁回复

简单询价用简短答复，复杂RFQ或方案比价展开以下流程，非价格询盘不强行报价：

1. 识别客户比较标准：单价、配置、交付、服务还是首批投入，并对齐比较口径。
2. 推荐一套适配方案：以FABMP连接需求、真实差异和证据。
3. 有真实取舍才提供备选：说明配置、采购安排或服务改变带来的收益与限制，不强造三档套餐。
4. 说明报价边界：币种、单位、规格、数量依据与适用商业条件，区分包含、不包含和待确认。
5. 按采购阶段推进下一步：确认规格/数量、选择方案、样品验证或技术评审。

差异化报价不是编造优势或擅自让价；报价、折扣、MOQ、账期及交期均须有有效依据。总成本或节省金额必须有可核查的输入和计算条件。

#### 针对性报价的五部分

| 部分 | 内容 |
| --- | --- |
| 需求理解 | 复述客户已确认的用途、数量、市场及交付要求，标出仍需验证的假设 |
| 推荐方案 | 根据这些要求选择已确认可供的型号、配置、包装和服务 |
| 推荐理由与证据 | 说明选择理由，提供真实规格、测试或其他证明，未进行测试不写已通过 |
| 价格与条件 | 明确配置、数量、币种、单位、贸易条件及包含范围，补齐适用商业条件 |
| 备选与下一步 | 有真实取舍才给备选；确认一项最关键的后续事项 |

简单询价可以把五部分压缩到短邮件，复杂RFQ可以展开为明细表。标准产品同样能给出针对性报价：关键是需求、方案、理由与条件相互对应，不是自动打折或更改MOQ。内部成本、底价及利润不进入客户文件。

教学示例（条件式，不是实际报价）：若客户已确认自有品牌、小批量测试，且我方确有适用方案，可说明为何推荐该产品与包装；报价基于已批准数量档位和条件。另一包装只有确实可供时才作为备选，并说明成本或交期变化；资料缺失时标待确认，不补造数字。

#### 第一段：快速给答复，绝不墨迹

先回答客户最关心的问题。询价时优先给已批准的准确价格；只有真实配置或数量档位支持时才给区间，并说明条件。没有报价依据则索取关键资料，不编造数字；非价格询盘直接回答实际问题。

不要先介绍公司历史、堆砌客套话，或用一串问题挡住报价。客户应首先知道“大致多少钱、对应什么产品和用途”。

#### 第二段：展示核心差异化

选择一个真正影响客户选择的可验证差异，可以是工艺、配置、测试/采购安排、服务或已批准的交付条件，而不局限于制造工艺。

这一步的设计意图是让客户有能力比较价格背后的工艺和使用结果。执行时必须有依据：说明我方真实工艺、应用价值及验证方式；没有竞争对手证据时，不把“同行做不到”写成事实断言。优先揭示容易被忽略、却会影响使用或业务结果的比较条件。

#### 第三段：CTA，推进一个有用的下一步

数量会影响报价或可行性时可以问；已知信息不重复问。根据采购阶段，选择确认规格/数量、选择方案或安排验证等主要动作，不强制使用A/B应用选项。

例如，在产品和客户背景适用时，可以问：“主要用于 A. 自有品牌零售，还是 B. 专业门店使用？”选项必须能帮助下一步推荐。如果客户已经说明用途，就问下一个必要的应用细分，不重复问已知信息，也不强行制造二选一。

### 5. 使用成熟理论优化回复

使用福格行为模型、社会心理学等理论，检查回复为什么值得回答、是否容易回答、下一步是否清楚。

福格行为模型强调行为发生需要动机（Motivation）、能力（Ability）和提示（Prompt）同时出现。本 Skill 将其用于回复设计：

- 动机：快速回应价格与场景，并说明与客户业务、联系人工作相关的价值。
- 能力：减少阅读与思考负担，让客户不必查表或内部开会就能回复。
- 提示：只给一个明确、轻量的 CTA，例如选择 A 或 B。

社会心理学方面，先提供有用信息，再提出轻量请求；通过具体比较条件辅助判断；有真实且相关的案例时才使用社会证明。不制造虚假稀缺、权威、口碑或焦虑。

理论用于指导设计，不保证回复或成交。FABMP在这里是价值表达框架，不宣称它是统一实验验证的心理学定律。具体理论效果需核对研究来源，实际效果需通过真实询盘反馈检验。

福格模型官方来源：[Fogg Behavior Model](https://www.behaviormodel.org/home)。

## 执行时的补充规则

- 报价必须来自我方有效资料，保留币种、单位、配置及必要条件；不能凭市场印象编造价格范围。
- 只有确定价格时就给确定价格；需要报价却缺少依据时索取资料，带占位的报价稿标为不可直接发送，也可先起草不含未经核实价格的澄清回复。
- 工艺、认证、性能、案例与交期必须有依据；拟进行的验证不能写成已完成的证据。
- 不混用不同品牌或相邻型号的产品事实。
- 三段式默认适用于即时询盘首回复；正式 RFQ、复杂技术选型和售后问题优先满足客户实际要求。
- 只研究和起草，不自动发送消息，也不自动修改客户记录。

## 使用方式

提供询盘原文，以及已有的客户公司或网站、联系人职位、我方产品资料、报价条件与工艺证据。信息不全也可以开始，Skill 会区分可完成部分与关键缺口。

```text

我方产品与报价依据：……
已验证工艺或证据：……
```

## 固定交付与两个Skill的交接

本Skill默认交付：

1. 《询盘问题与回复策略表》，附必要的客户判断、Meaning假设及FABMP映射。
2. 初次回复：可复制的客户语言正文；需要报价时包含五部分信息。关键资料或承诺未确认时标待补，不能标为可直接发送。

后续由teco-b2b-customer-follow-up交付第三项《四轮跟进计划与话术》。内部交接记录不额外算一份学员作业。

交接字段：目标客户/联系人、产品与资料版本、已确认需求及假设、已答复内容与承诺、未决问题、CTA、已提供及待准备材料、客户状态/联系约定、发送状态与实际日期/渠道、依据及更新时间。

邮件未发送时使用“拟答复/拟提供”，日期未知保留待确认。只有用户确认或真实发送记录才能标为已发送；生成草稿不代表送达或阅读。最终发送稿优先于初稿。跟进Skill以交接与最新沟通为输入，不重跑无关背调。

默认对话交付，不自动写入知识库；有明确保存请求时按指定位置保存，不覆盖基础资料。只需要正文时可精简其余内容，但不能隐藏关键缺项。
